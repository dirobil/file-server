HTTPS и шифрование в браузере (WebCrypto)

{{tls_badge}}

Браузер разрешает WebCrypto API только на HTTPS или localhost. Самоподписанный сертификат выпускается автоматически для указанного адреса; при первом открытии https-страницы примите его («Дополнительно → Перейти на сайт») либо добавьте /ca.crt в доверенные. После этого на главной появится рабочий тумблер «Шифровать в браузере».
