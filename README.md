# Файловый сервер (Rust + axum)

Веб-сервер для обмена файлами: пользователи загружают файлы на страницу,
любой может скачать их из списка. Хранилище настраивается через админ-панель.

## Технологии

- **axum** — HTTP-фреймворк (маршруты, multipart-загрузка, извлечение форм/параметров)
- **tokio** — асинхронный рантайм
- **tower-http** (`ServeDir`) — раздача статики
- **serde** — десериализация форм/запросов
- **tokio-util** — стриминг файлов при скачивании (без загрузки в память)

## Запуск

```bash
cargo run                # сервер на http://0.0.0.0:3000
BIND=127.0.0.1:8080 cargo run   # другая адрес/порт
STORAGE_DIR=/data/files cargo run  # предзаполнить хранилище (иначе сервер «не настроен»)
```

## Как это работает

1. Пока администратор не выбрал директорию для хранения, на главной странице
   показывается сообщение: **«Сервер ещё не настроен — обмен файлами работать не будет»**.
   Загрузка/скачивание в этом состоянии возвращают `503`.
2. **Админ-панель** — `/admin`: поле для абсолютного пути к директории хранилища
   (папка создаётся автоматически), кнопка сброса настройки.
3. **Главная** — `/`: drag-and-drop / выбор файлов (до нескольких сразу, лимит 100 МБ
   на файл), список доступных файлов с кнопками «Скачать» и «Удалить».

## Маршруты

| Метод | Путь              | Назначение                          |
|-------|-------------------|-------------------------------------|
| GET   | `/`               | главная (или заглушка «не настроен») |
| POST  | `/upload`         | multipart-загрузка файлов           |
| GET   | `/download/{name}`| скачивание файла                    |
| POST  | `/delete/{name}`  | удаление файла                      |
| GET/POST | `/admin`       | настройка директории хранилища      |

## Безопасность

- Имена файлов санитизируются (убираются пути, управляющие символы, `..`).
- Скачивание/удаление возможно только для файлов внутри настроенной директории
  (path traversal блокируется, проверено: `../` → `404`).
- HTML экранируется во всех страницах; совпадающие имена получают суффиксы `(1), (2)…`.
